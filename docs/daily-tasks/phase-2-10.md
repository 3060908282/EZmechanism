## 任务清单

- [ ] 2.10.1 编写 `cgd/pap/pap_runtime.py` 框架
  - 创建 PAP 运行时模块，定义 `PAPRuntime` 类
  - Per CGD_MASTER_PLAN §4.7 Phase 2 (完整PAP管线，含DS3过滤)
  - 数据流: SMILES + PDB → DS2先验验证 → 口袋锚定 → 双DOF旋转 → DS3筛选 → 碰撞检测 → 最优选择
  - **验收**: 模块框架可导入运行

- [ ] 2.10.2 Step 1: DS2 先验验证
  - 在执行 PAP 前，先验证活性位点几何合理性
  - 检查: 催化残基间的距离是否在 DS2 的 P5-P95 范围内
  - 如果活性位点几何异常 (距离超出 P5-P95) → 标记 warning，降低后续置信度
  - DS2 仅作为先验检查，不用于筛选配体放置
  - **验收**: DS2 先验验证逻辑正确

- [ ] 2.10.3 Step 2: 口袋锚定放置 (复用 phase-2-9)
  - 调用 `PocketAnchorPlacer` 的锚定逻辑
  - 生成 100 个构象 (ETKDGv3)
  - 锚定反应原子到口袋锚点
  - **验收**: 放置步骤复用 phase-2-9 代码

- [ ] 2.10.4 Step 3: 双自由度旋转采样
  - 旋转自由度1 (θ,φ): Fibonacci 球面采样 50 个方向
  - 旋转自由度2 (ψ): 绕反应原子-锚点轴自旋，等间隔 10 个
  - 总候选: 100 (构象) × 50 (θφ) × 10 (ψ) = 50,000 个
  - 每个候选的计算:
    1. 先按 Fibonacci 方向旋转 (θ,φ)
    2. 再绕反应原子-锚点轴自旋 (ψ)
  - **验收**: 双DOF旋转采样生成 50,000 个候选

- [ ] 2.10.5a ⚠️ DS3 数据质量预检查
  - **在执行筛选前，必须验证 DS3 数据覆盖度**
  - 检查项:
    1. 当前 PDB 条目的 residue-role 组合是否在 DS3 Scene A 中有对应分组
    2. 对应分组的 n_obs 是否 ≥ 10 (Level 1) 或 ≥ 30 (Level 0)
    3. P5-P95 范围是否合理 (P95 - P5 > 0.5Å，非退化区间)
  - 如果 DS3 数据覆盖不足:
    - 标记 `ds3_coverage = "low"`，记录缺失的 residue-role 组合
    - 降级策略: 仅用 Level 0 阈值筛选 (放宽粒度)
    - 严重不足时: 仅用碰撞检测筛选 (跳过 DS3)，置信度降级
  - **验收**: DS3 数据质量检查逻辑正确，覆盖不足时有降级方案

- [ ] 2.10.5b Step 4: DS3 Scene A 阈值筛选
  - **关键**: 筛选用 DS3 (Scene A P5-P95)，而非 DS2!
  - 对每个候选放置:
    1. 计算残基-配体距离 (D1-D6)
    2. 查询 DS3 Scene A 的 P5 和 P95 阈值
    3. 检查: 所有相关 D 类别距离是否在 P5-P95 范围内
    4. 通过 → 保留，不通过 → 淘汰
  - 优先使用 Level 1 阈值 (细粒度)；如果 Level 1 n_obs < 10，回退到 Level 0
  - **验收**: DS3 筛选逻辑正确，使用 Scene A 阈值

- [ ] 2.10.6 Step 5: 空间碰撞检测
  - 对通过 DS3 筛选的候选:
    1. 提取配体重原子坐标
    2. 提取蛋白质骨架原子坐标 (CA, C, N, O)
    3. 计算配体重原子与最近骨架原子的距离
    4. 阈值: 如果任何配体原子距离骨架原子 < 1.5Å → 淘汰 (碰撞)
  - 使用 KD-Tree (scipy.spatial.cKDTree) 加速最近邻搜索
  - **验收**: 碰撞检测阈值 1.5Å 正确，KD-Tree 加速有效

- [ ] 2.10.7 Step 6: 选择最优放置
  - 对通过 DS3 筛选 + 碰撞检测的候选:
    1. 计算 ds3_score: 基于各 D 类别距离与 DS3 P50 的接近程度
    2. `ds3_score = Σ(w_j × (1 - |d_j - d_p50_j| / (d_p95_j - d_p5_j)))` 对每个 D 类别 j
    3. 按 ds3_score 降序排列
    4. 返回 top-5 候选
  - 如果通过筛选的候选 < 5 → 增加旋转采样到 200 方向重试
  - 如果仍无通过 → 返回空列表 + confidence=Rejected
  - **验收**: 排序和选择逻辑正确

- [ ] 2.10.8 性能优化
  - 50,000 个候选的 DS3 筛选需高效:
    - 向量化距离计算 (numpy)
    - 提前退出: 如果任一 D 类别超范围即淘汰，不计算后续
    - KD-Tree 碰撞检测 (仅对 DS3 通过的候选)
  - 目标: 单个 PDB 的 PAP 运行时间 < 60 秒
  - **验收**: 运行时间在可接受范围内

- [ ] 2.10.9 验收测试
  - 选择 1BTL + benzylpenicillin 进行完整 PAP 管线测试
  - 验证:
    - DS3 筛选通过的候选数 ≥ 5
    - 最优放置的配体与催化残基距离合理
    - 无碰撞 (所有配体原子距骨架 ≥ 1.5Å)
  - **验收**: PAP 管线端到端可运行，输出合理结果

## 常见陷阱

1. **DS3 vs DS2 筛选混淆**: DS2 仅用于 Step 1 先验验证活性位点，DS3 用于 Step 4 筛选配体放置；两者不能混用
2. **D1 距离退化**: PAP 将反应原子固定在锚点，D1 距离由锚点唯一确定，DS3 筛选对 D1 无区分力 (见 IMPLEMENTATION_PLAN 注释)；这是可接受的设计特征
3. **50,000 候选的计算量**: 虽然每次只算几个距离，但 50,000 × 6 个距离 = 300,000 次距离计算；需向量化
4. **Level 0/Level 1 回退逻辑**: 部分罕见 (D 类别, role, residue_type) 组合可能无 Level 1 阈值，必须回退到 Level 0
5. **KD-Tree 内存**: 蛋白质骨架原子通常 500-2000 个，KD-Tree 构建很快；但超大蛋白 (如核糖体) 需注意
6. **重试策略**: 增加旋转采样到 200 方向意味着 100×200×10=200,000 候选，计算量翻 4 倍；设置最大重试次数 (1次)
7. **ds3_score 权重**: MVP 阶段各 D 类别等权；后续可根据 D 类别的统计可靠性调整权重
8. **P5-P95 范围过宽/过窄**: 如果 DS3 数据量不足，P5-P95 范围可能过大 (几乎不过滤) 或过窄 (全部淘汰)；需监控通过率
9. **DS3 数据覆盖度不足**: 验收标准"DS3 筛选通过的候选数 ≥ 5"的前提是 DS3 数据覆盖了足够的 residue-role 组合。如果 DS3 Scene A 中对应分组 n_obs 不足或完全缺失，可能无法通过任何候选。2.10.5a 的预检查会识别这种情况并启用降级策略
