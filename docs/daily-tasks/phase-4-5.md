# Phase 4-5: 阈值校准

**Phase**: 4  
**任务编号**: 4.5  
**前置依赖**: phase-4-4 (CGPS综合评分可运行)  
**阻塞后续**: Phase 5 (争议检测需要灰色区间), Phase 7 (验证需要校准参数)  
**预计耗时**: 2天 (含校准失败迭代流程)

> ⚠️ **校准-评估一致性**: Phase 7 的 E2-E5 评估在 full-pool 子集上进行 (E1 双阈值分类后)。若 Phase 7 发现校准与评估不匹配，需在 full-pool 子集上重新校准。当前校准使用全部 M-CSA 数据 (含 limited_pool 条目)，权重可能不是 full-pool 最优。

## 任务清单

- [ ] 4.5.1 准备 M-CSA 基准数据
  - 从 M-CSA 缓存中提取已知机制:
    - 正样本: M-CSA 记录的催化机制 (residues + steps + PDB)
    - 负样本构造策略 (正负比例 ~1:3):
      - **硬负样本 (占50%)**: "看似合理但实际错误"的候选
        - 同EC类不同机制: 同EC主类但不同子类的已知机制，残基组合合理但对应错误底物
        - 部分匹配: 保留1-2个正确残基，替换其余为同EC类常见残基
        - 角色互换: 正确残基组合但角色分配错误 (如亲核试剂与酸/碱互换)
      - **软负样本 (占50%)**: 随机残基组合
        - 不同EC类残基随机组合
        - 不可能组合 (如两个金属+一个水作为催化残基)
  - 80/20 训练/测试划分 (按 M-CSA ID 分层，确保无数据泄露)
  - **验收**: 训练集/测试集划分合理，正负样本比例 ~1:3; 硬负样本CGPS评分低于正样本P25

- [ ] 4.5.2 实现网格搜索校准
  - 路径: `cgps/calibration.py`
  - 搜索参数:
    - w1 (S_co 权重): [0.1, 0.2, 0.3, 0.4]
    - w2 (S_geo 权重): [0.3, 0.4, 0.5, 0.6]
    - w3 (S_path 权重): [0.05, 0.1, 0.15, 0.2]
    - θ_low: [0.2, 0.25, 0.3, 0.35]
    - θ_high: [0.6, 0.65, 0.7, 0.75]
  - 约束: w1+w2+w3 = 1.0
  - 目标: 最大化 Top-3 准确率 (已知机制排前3)
  - **验收**: 网格搜索可运行

- [ ] 4.5.3 执行校准
  - 在训练集上运行网格搜索
  - 选择最优参数组合
  - 在测试集上验证 (不调参)
  - 记录: 训练集/测试集准确率、最优参数
  - **验收**: 测试集准确率 > 训练集 × 0.85 (无明显过拟合)

- [ ] 4.5.4 确定灰色区间
  - 在训练集上分析 CGPS 分数分布:
    - 正样本分布: P10, P50, P90
    - 负样本分布: P10, P50, P90
  - 灰色区间 = 正负样本分布重叠区域
  - θ_low ≈ 负样本 P90 (低于此大概率是负样本)
  - θ_high ≈ 正样本 P10 (高于此大概率是正样本)
  - **验收**: Weights determined, grey zone defined

- [ ] 4.5.5 输出校准参数
  - 路径: `cgps/calibrated_params.json`
  - 结构:
    ```json
    {
      "w1": 0.25,
      "w2": 0.60,
      "w3": 0.15,
      "theta_low": 0.28,
      "theta_high": 0.72,
      "calibration_date": "2026-...",
      "train_accuracy": 0.85,
      "test_accuracy": 0.78,
      "n_train": 800,
      "n_test": 200,
      "calibration_iterations": 1,
      "negative_sample_stats": {
        "hard_negatives": 600,
        "soft_negatives": 600,
        "hard_negative_p25_score": 0.35
      }
    }
    ```
  - **验收**: 校准参数文件格式正确，可被 CGPSScorer 加载

- [ ] 4.5.6 ⭐ 校准失败迭代流程
  - 若测试集准确率 < 训练集 × 0.85 (过拟合):
    1. 缩小网格搜索范围 (围绕当前最优值±1步)
    2. 增加约束: 限制 w1/w2/w3 变化幅度 (相邻迭代权重变化 ≤ 0.05)
    3. 重新执行 4.5.2-4.5.3
  - 最多迭代3次，记录每次迭代的参数和准确率
  - 若3次迭代后仍失败:
    - 记录诊断报告: 过拟合程度 (train_acc - test_acc)、参数敏感度分析、硬负样本难度分布
    - 标记 CGPS 为 "需人工校准"，使用当前最优参数继续后续Phase
  - 若灰色区间过宽 (θ_high - θ_low > 0.5):
    - 分析原因: 正负样本区分度不足
    - 调整硬负样本比例 (提高至70%)
    - 重新执行 4.5.1-4.5.4
  - **验收**: 失败时有明确诊断输出; 校准迭代记录完整; 灰色区间宽度 ≤ 0.5

## 常见陷阱

1. **负样本构造**: 随机残基组合可能过于简单 (负样本太容易识别)，需加入"看似合理但实际错误"的硬负样本
2. **过拟合风险**: 5 个参数在 800 样本上网格搜索，参数空间较大，可能过拟合 → 测试集验证是关键
3. **数据泄露**: 80/20 划分需按 M-CSA ID 分层，同一 M-CSA 条目的不同机制不可跨集
4. **权重约束**: 网格搜索需确保 w1+w2+w3=1.0，可以用 w3=1-w1-w2 减少搜索维度
5. **Scene C 样本不足**: 无 PDB 的酶可能样本少，Scene C 的校准可能不稳定
