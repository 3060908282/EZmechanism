## 任务清单

- [ ] 2.11.1 扩展 `cgd/water/scorer.py` 支持完整5维
  - 在现有 `CatalyticWaterScorer` 类中添加维度4和维度5
  - 更新综合评分公式: `score = (dim1 + dim2 + dim3 + dim4 + dim5) / 5`
  - 保持向后兼容: 可选择仅使用3维或5维评分
  - **验收**: 5维评分接口可用

- [ ] 2.11.2 维度4: 同源保守性
  - 利用 phase-2-7 的同源保守性验证结果
  - 逻辑: 如果该水分子位置在多个同源结构中都存在水分子 → 保守 → 高分
  - 步骤:
    1. 获取同源结构列表 (从 phase-2-5 结果)
    2. 对每个通过 TM-align 的同源结构 (High/Medium tier):
       a. 将同源结构变换到参考坐标系
       b. 提取水分子坐标
       c. 计算同源水分子与参考水分子最近距离
    3. 统计: 在 <1.5Å 范围内有水分子的同源结构数量
  - 评分规则:
    - ≥3 个同源结构有对应水 → 1.0 (高度保守)
    - 1-2 个同源结构有对应水 → 0.5 (中度保守)
    - 0 个同源结构有对应水 → 0.0 (不保守)
  - **验收**: 同源保守性评分逻辑正确

- [ ] 2.11.3 维度5: 化学上下文
  - 逻辑: 判断水分子是否处于合理的化学环境中 (不是金属配位水)
  - 维度3 (金属排除) 已判断是否为金属配位水，维度5 进一步检查化学合理性:
    1. 水分子周围是否有合理的氢键供体/受体 (催化残基、其他水、配体原子)
    2. 排除: 水分子仅与金属离子配位 (已在维度3处理)
    3. 新增: 水分子是否与催化残基形成氢键 (距离 < 3.5Å + 角度合理)
  - 评分规则:
    - 与 ≥1 个催化残基形成氢键 → 1.0
    - 与催化残基距离 < 5Å 但无明确氢键 → 0.5
    - 不在任何催化残基附近 → 0.0
  - 简化实现: 不做精确氢键角度计算 (Phase 5.5 完善)，仅用距离判定
  - **验收**: 化学上下文评分逻辑正确

- [ ] 2.11.4 更新综合评分与阈值
  - 5维等权: `score = (dim1 + dim2 + dim3 + dim4 + dim5) / 5`
  - 更新阈值判定 (同3维):
    - score ≥ 0.6 → "catalytic"
    - 0.3 ≤ score < 0.6 → "pending"
    - score < 0.3 → "ignore"
  - 新增: 如果3维评分 ≥ 0.6 但5维评分 < 0.6 → 降级为 "pending" (同源保守性不足)
  - **验收**: 5维评分阈值判定正确

- [ ] 2.11.5 批量处理10个已知催化水
  - 选择10个M-CSA条目中的已知催化水 (从文献或M-CSA标注获取)
  - 运行5维评分器
  - 期望: ≥8/10 被正确识别为 "catalytic"
  - 记录每个水分子的5维得分明细
  - **验收**: 10个已知催化水的5维评分结果合理

- [ ] 2.11.6 与3维评分对比
  - 对比3维和5维评分的差异
  - 5维应减少假阳性 (金属配位水被维度4/5降低评分)
  - 5维应保持真阳性 (已知催化水仍 ≥ 0.6)
  - **验收**: 5维评分的精确度 ≥ 3维评分

## 常见陷阱

1. **同源水分子定位精度**: TM-align 是全局比对，局部水分子位置可能偏差较大 (1-2Å)；1.5Å 容差需验证是否合理
2. **水分子密度差异**: 同源结构的结晶条件不同，水分子数量和位置差异大；部分同源结构可能缺少该水分子
3. **维度3和维度5重叠**: 维度3 (金属排除) 和维度5 (化学上下文) 都涉及金属相关判断，但角度不同：维度3 判断"是否金属配位"，维度5 判断"是否有合理氢键网络"
4. **5维等权假设**: 5个维度可能不应等权；例如距离维度可能比同源保守性更重要；但 MVP 等权是合理的起点
5. **氢键角度简化**: MVP 仅用距离判定氢键 (< 3.5Å)，不做角度判断；可能导致部分假阳性 (几何不合理但距离够近)
6. **PDB 水分子编号不一致**: 不同 PDB 的水分子残基编号无对应关系，只能通过空间位置匹配
