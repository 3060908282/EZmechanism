## 任务清单

### 6.4: CGD管理界面

- [ ] 6.4.1 实现数据集浏览页面

    - DS1: role_pair 频率表 (可排序/过滤)
    - DS2: 距离分布直方图 (交互式)
    - DS3: Scene A/B 分布 + 距离热图

- [ ] 6.4.2 实现覆盖度仪表盘

  - 实时刷新: 调用 `/cgd/stats` 端点
  - **验收**: Dashboard shows dataset stats

### 6.5: 性能优化

- [ ] 6.5.1 实现缓存优化
  - PDB 文件缓存: 本地文件系统缓存 (已下载的 PDB 不再请求)
  - RCSB API 缓存: 搜索结果缓存 (TTL=1h)
  - DS2/DS3 阈值缓存: 内存常驻 (启动时加载)
  - LLM 响应缓存: 相同 prompt → 返回缓存结果
  - **验收**: 重复请求走缓存，无冗余网络调用

- [ ] 6.5.2 实现并行化
  - Top-N 候选并行评估 (ThreadPoolExecutor)
  - Agent③④⑤ 并行调用
  - PDB 下载与解析异步执行
  - **验收**: 并行化后单请求总耗时显著降低

- [ ] 6.5.3 实现批处理
  - 批量验证: 多个酶同时提交 → 队列处理
  - 批量导出: 验证结果导出为 CSV/JSON
  - 进度追踪: 批处理任务进度
  - **验收**: 批处理模式可运行

- [ ] 6.5.4 性能测试和优化
  - 基准测试:
    - 单候选 Scene A: 目标 <5s
    - Top-5 候选: 目标 <30s
    - Scene C (无3D): 目标 <3s
  - 瓶颈分析: 识别最慢的阶段
  - 优化: 预计算、延迟加载、增量更新
  - **验收**: Response time <5s for single candidate

## 常见陷阱

1. **缓存一致性**: DS5 更新后需失效相关缓存，避免返回过期数据
2. **并行资源竞争**: 多个候选同时下载同一 PDB → 需去重
3. **批处理 OOM**: 大批量任务可能导致内存溢出，需限制并发数
4. **前端性能**: 大数据集的图表渲染可能卡顿，需做虚拟滚动或分页
