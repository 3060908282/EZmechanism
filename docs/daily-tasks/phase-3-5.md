# Phase 3-5: 统计消歧

**Phase**: 3  
**任务编号**: 3.5  
**前置依赖**: phase-2-3 (DS3≥50 samples 的分组), phase-3-3 (DS5映射)  
**阻塞后续**: phase-3-6 (DS3迭代优化)  
**预计耗时**: 2天  

---

## 任务清单

- [ ] 3.5.1 编写统计消歧模块
  - 路径: `cgd/statistics/statistical_disambiguator.py`
  - 核心逻辑: 当 DS3 某分组有 ≥50 个样本时，计算 P50 几何先验
  - P50 = 该分组距离分布的中位数 (最可能值)
  - **验收**: 模块框架可导入运行

- [ ] 3.5.2 筛选合格分组
  - 读取 DS3 数据集
  - 对每个 (distance_category × role) 分组，检查 n_obs
  - 保留 n_obs ≥ 50 的分组 (Level 0 粗粒度)
  - 保留 n_obs ≥ 30 的分组 (Level 1 细粒度，需标注 confidence="medium")
  - 统计: 合格分组数 / 总分组数
  - **验收**: 筛选逻辑正确，分层标注合理

- [ ] 3.5.3 计算 P50 几何先验
  - 对每个合格分组，计算各距离维度的 P50:
    - D1-D6: 距离中位数 (Å)
    - A1-A3: 角度中位数 (°)
  - P50 代表"最可能的几何构型"
  - 输出: `data/derived/ds3_p50_priors.json`
  - **验收**: P50 值计算正确，与 DS3 原始分布一致

- [ ] 3.5.4 实现消歧逻辑
  - 场景: 当 1:N 映射有多条候选 SMARTS，如何选择？
  - 方法: 用 P50 几何先验消歧
    1. 对每条候选 SMARTS 变换，推断其产生的键变化
    2. 计算推断距离与 P50 先验的偏差
    3. 选择偏差最小的候选
  - 偏差度量: `Σ |d_inferred - d_p50| / n_dimensions`
  - **验收**: 消歧逻辑可从多候选中选择最优

- [ ] 3.5.5 评估消歧效果
  - 用 M-CSA 已知机制做基准:
    - 不消歧: 随机选候选 → 准确率 = 1/N
    - 消歧: P50 先验选候选 → 准确率应显著提高
  - 目标: 消歧准确率比随机提高 >10%
  - **验收**: Disambiguation improves match accuracy >10%

## 常见陷阱

1. **样本量阈值**: DS3 分组的 n_obs 可能远低于 50，实际可消歧的分组可能很少
2. **P50 稳定性**: n_obs=50 时 P50 可能仍有较大置信区间，需标注不确定性
3. **消歧前提**: 本任务的消歧逻辑为 Phase 5 的 1:N 映射做准备，当前无 1:N 数据可测试，需用模拟数据
4. **距离维度选择**: 不是所有维度都有区分力，需分析哪些维度的 P50 先验最有消歧价值
